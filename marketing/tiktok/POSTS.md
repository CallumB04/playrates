# TikTok posts

What has gone up on [@playratesapp](https://www.tiktok.com/@playratesapp),
in the order the posts are meant to go out. When one is live, tick it and
add the date and its link:

    - [x] [best-horror-games](posts/best-horror-games.json) — 2026-10-14 — https://www.tiktok.com/@playratesapp/photo/…

The admin page (`/admin/tiktok`) reads this file when the site is built, so
a tick shows there once it is pushed to main and deployed. A new post goes
on the list when its file is added; `npm run tiktok` warns if it isn't.
